# **App Name**: Celesther's Digital Canvas

## Core Features:

- Dynamic Project Display: Interactive project showcase with animated transitions between projects.
- Adaptive Layout: Responsive layout that adapts to various screen sizes, maintaining a consistent design.
- AI Project Summarizer: AI-powered tool to generate project descriptions based on uploaded project files or images. Use a LLM tool to assess file content.
- Enhanced Contact Form: A contact form with input validation to ensure all required fields are completed before submission, providing real-time feedback to the user.
- Skill Visualization: Animated skill bars to visualize proficiency levels in various tools and technologies.

## Style Guidelines:

- Primary color: Vivid cyan (#0ea5e9) for a modern, tech-forward feel, taken directly from user's config
- Background color: Dark gray (#121820) to provide a professional, sophisticated backdrop, creating contrast with the vibrant primary color. Chosen to complement the existing design.
- Accent color: Electric purple (#BE29FF) to highlight key elements and calls to action with a burst of creativity and energy.
- Body and headline font: 'Poppins' (sans-serif) to maintain a clean, modern, geometric aesthetic throughout the portfolio. Note: currently only Google Fonts are supported.
- Use Font Awesome icons with consistent styling and sizing across the site. Color the icons white or the primary color for emphasis.
- Implement subtle animations on scroll and hover to enhance user engagement and provide visual feedback, particularly for skill bars and project cards.
- Use a grid-based layout to create a visually structured and balanced interface. Ensure consistent spacing and alignment across all elements for a cohesive user experience.
